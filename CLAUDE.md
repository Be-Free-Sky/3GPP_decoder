# UI Rules

Always follow:
- Emil Kowalski visual style - https://github.com/emilkowalski/skills/
- Taste UI component system - https://github.com/Leonxlnx/taste-skill

Preferred stack:
- Next.js
- TailwindCSS
- Shadcn UI

Never use:
- Bootstrap
- Material UI
- Outdated card designs
- Generic admin dashboard styling

Prefer:
- Modern SaaS design
- Premium gradients
- Smooth animations
- Glassmorphism
